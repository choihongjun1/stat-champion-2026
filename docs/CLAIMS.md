# 주장 계약 (CLAIMS)

> 1~4절 손유성 작성, 5절 박안석 작성. 박안석·최홍준 검토 반영(2026-10-04, #69). 근거: Issue [#49](https://github.com/choihongjun1/stat-champion-2026/issues/49)·[#54](https://github.com/choihongjun1/stat-champion-2026/issues/54), `docs/DECISIONS_W3.md`, 제출 화면 #48·제출 번들 #65(`submission-static-0.1`).
> 보고서·화면·첨부 산출물에서 **무엇을 주장하고 무엇은 주장하지 않는지** 정한다. 1~4절은 손유성, 5절은 박안석 추가 규칙이다. 이 문서와 결정 기록(`DECISIONS_W3.md`)이 다르면 임의로 고르지 않고 충돌을 먼저 보고한 뒤 결정 기록에 맞춰 고친다.
> 수치는 A4(수치 계약)에 따라 재생성 이후 확정하며, 이 문서의 문장 틀에 들어가는 숫자는 A4 표에 있는 값만 쓴다.

## 1. 단계별 쓴다 / 쓰지 않는다

보고서는 정확한 용어, 화면은 사장님이 바로 이해할 수 있는 말("해요체")로 쓴다. 통계 용어(AUC, 95% CI, 영업이익률 등)는 보고서와 화면의 '자세히 보기'에만 쓴다(T1 확인).

### 1-1. 탐지 (Stage 1)

| | 쓴다 | 쓰지 않는다 |
|---|---|---|
| 보고서 | "향후 12개월 상대 위험 수준"(위험 등급 low·mid·high). high는 "평균보다 폐업이 많이 관측된 집단"이라고 쓰고, **독립 검증 구간의 lift 95% CI 하한이 1.5 이상일 때만** "(약 2배)"를 붙인다(S10). 대표 성능은 채택 모형의 10-origin 평균 AUC를 모델 클래스·fold·표본과 함께(S9) | 개인 확률·예측 구간("폐업 확률 38%", "29~47%"), "폐업률 2배", "AI가 폐업을 예측", 서로 다른 AUC(0.6219·0.6268·0.693 등)를 같은 성능처럼 나열(S9) |

## 3. 표기 규칙

- **모형:** 탐지 모형은 "HistGradientBoosting(HGB)"(S13). "LightGBM"이라고 쓰지 않는다.
- **성능:** 대표 성능은 채택 모형의 10-origin 평균 AUC, pooled 값은 부록(S9). 재생성 전 잠정값(0.6280)은 본문에 쓰지 않는다.
- **CI:** 탐지는 "점포 클러스터 부트스트랩", DML은 "DoubleML 추론(무가중)"이라고 밝힌다. 두 CI를 하나로 통일해 부르지 않는다(S12).
- **철회 수치:** 3.3%, 8.8~12.6%, "오탐-폐업 상관", "대기시간 줄이기" 카드는 철회 이력(`DECISIONS_W3.md` 4절)에만 둔다(S12).
- **조사명·데이터:** MDIS는 "소상공인실태조사 2023"(F7). 계획서 대비 변경 표에서도 틀린 조사명을 문자열로 다시 쓰지 않고 "계획서의 MDIS 조사명 오기를 정정"이라고 쓴다(CL-11은 error라 줄 예외를 두지 않는다). 폐업은 "인허가 폐업일자 기준"이다. 온라인 지표는 "블로그 언급 수"(5절).
- **용어:** "처방" 대신 "대응 방향"(T1). 계획서 대비 변경을 설명할 때만 "처방"을 쓴다. 보고서의 근거 상태는 "조건부 연관성 관찰 / 확인 불가", 정책 상태는 "자격·모집 확인 / 미확인"(T1). 화면의 정책 문구는 1-4를 따른다.
- **실제 점포:** "비식별 실제 사례 A/B/C" + 구·업종(T5).
- **수치:** 본문·화면의 모든 수치는 A4 수치 출처표(metric 정의·분석 창·표본·artifact·commit)에 있는 값만 쓴다.

## 5. 추가 규칙 (2026-10-01 저녁 추가, 박안석)

위 1~4절(손유성 초안 영역)은 고치지 않고 아래 규칙만 덧붙인다. 근거는 #48 리뷰와 Issue #49(T1·T3·T4)다.

- **온라인 지표:** "블로그 언급 수"(또는 "온라인 언급")라고 쓴다. "후기"·"리뷰"는 쓰지 않는다. 온라인 지표는 블로그 월별 언급 수이고 리뷰 텍스트 분석은 하지 않았다.
- **지원사업 제목:** "가게 업종·지역으로 찾은 지원사업"이다(제출 화면은 "…지원사업이에요"). "자격 조건이 맞는 지원사업"은 `check_required` 사업까지 자격을 단정하므로 영역 제목으로 쓰지 않는다(2026-10-04 박안석 승인, #69). "받을 수 있는 지원"은 수혜를 암시하므로 쓰지 않는다.
- **정책 카드:** 위험요인과 연결하는 "○○ 관련" 표시는 금지한다(T4). 정책은 업종·지역·자격 기준으로만 보여 준다.
- **위험요인 문장:** "모형은 이 점을 위험을 높이는 신호로 봤어요"(낮추는 경우 "…낮추는 신호로 봤어요") 틀을 쓴다. "…가게들은 문을 닫는 경우가 더 많았어요" 같은 문장은 집단의 폐업률을 비교하지 않았으므로 쓰지 않는다. 사실 정보(업력, 블로그 언급 수)는 그대로 쓸 수 있다.
- **MDIS 조사명:** "소상공인실태조사 2023"이다. "창업기업실태조사"는 쓰지 않는다.
