# 주장 계약 (CLAIMS) — 뼈대

> **초안 — 손유성이 이어서 작성, 박안석 승인 전.** 근거: Issue [#49](https://github.com/choihongjun1/stat-champion-2026/issues/49), `docs/DECISIONS_W3.md` (T1·T3·T4·S5·S12·A3).
> 이 문서는 "쓴다 / 쓰지 않는다"의 뼈대다. 문구는 손유성이 보고서·화면 기준으로 채우고, 수치는 A4(수치 계약)에 따라 재생성 이후 확정한다.

## 1. 단계별 쓴다 / 쓰지 않는다

| 단계 | 쓴다 | 쓰지 않는다 |
|---|---|---|
| 탐지 | "향후 12개월 상대 위험 수준", "평균보다 폐업이 많이 관측된 집단(약 2배, S10 조건 충족 시)" | "폐업 확률 38%", 개인 확률·구간, "폐업률 2배", "AI가 폐업을 예측" |
| 진단 | "이 신호가 모형 예측을 위험 쪽으로 움직였습니다", "해석 민감" | "○○ 때문에 위험합니다", "원인은 ○○", SHAP를 인과효과로 서술 |
| 대응 방향 | "별도 분석(전국 2023 조사)에서 비슷한 조건 사업체 간 관계를 분석했습니다. 이 가게의 효과는 확인되지 않았습니다" | "효과 확인됨", "위험 ○%p 감소", "인과효과", 블로그 → 전자상거래 화살표 |
| 지원사업 | "자격 조건이 맞는 사업", "확인일 ○○", "신청 전 공식 공고를 확인하세요" | 상태 불명 사업에 "신청 가능", "이 사업을 받으면 위험이 줄어듭니다" |
| 개인정보 | — | 인증이 없다면 "본인만 볼 수 있습니다" |

## 2. 금지어 검사 목록 (W3-16에서 grep)

화면·보고서·첨부 산출물에서 아래 문자열을 검색한다. 이 문서와 `docs/DECISIONS_W3.md`의 철회 이력 부록은 금지어를 설명하기 위해 포함하므로 검사 대상에서 제외한다.

- `효과 확인`
- `인과효과`
- `폐업 확률`
- `38%`
- `29~47%`
- `3.3%`
- `8.8`
- `12.6%`
- `대기시간`
- `본인만 볼 수`
- `신청 가능` — 문맥 검사 필요: 지원사업 상태가 확인된 정책의 "신청 가능"(`apply_status`로 근거 있음)과 상태 불명·마감 정책의 "신청 가능"을 구분한다. 문자열만으로 오류로 판정하지 않는다(T4).

## 3. 표기 규칙

- 탐지 모형은 "HistGradientBoosting(HGB)"이라고 쓴다. "LightGBM"이라고 쓰지 않는다(S13).
- MDIS 조사명은 "소상공인실태조사 2023"이다(F7).
- "처방"은 "대응 방향"으로 쓴다(T1).
- 실제 점포를 보여줄 때는 "비식별 실제 사례 A"로 표기하고 이름·주소·ID는 공개하지 않는다(T5, A3).
- 대표 성능은 채택 모형의 10-origin 평균 AUC이며 모델 클래스·fold·표본을 함께 적는다(S9).

## 4. 남은 작업 (손유성)

- 단계별 문구의 보고서·화면 버전 작성, 수치 출처표 연결(A4)
- 신청서 제출본과의 대조(F6), 금지어 목록 보완
- 박안석 승인 후 이 문서의 "초안" 표시를 제거

## 5. 추가 규칙 (2026-10-01 저녁 추가, 박안석)

위 1~4절(손유성 초안 영역)은 고치지 않고 아래 규칙만 덧붙인다. 근거는 #48 리뷰와 Issue #49(T1·T3·T4)다.

- **온라인 지표:** "블로그 언급 수"(또는 "온라인 언급")라고 쓴다. "후기"·"리뷰"는 쓰지 않는다. 온라인 지표는 블로그 월별 언급 수이고 리뷰 텍스트 분석은 하지 않았다.
- **지원사업 제목:** "자격 조건이 맞는 지원사업"이다. "받을 수 있는 지원"은 수혜를 암시하므로 쓰지 않는다.
- **정책 카드:** 위험요인과 연결하는 "○○ 관련" 표시는 금지한다(T4). 정책은 업종·지역·자격 기준으로만 보여 준다.
- **위험요인 문장:** "모형은 이 점을 위험을 높이는 신호로 봤어요"(낮추는 경우 "…낮추는 신호로 봤어요") 틀을 쓴다. "…가게들은 문을 닫는 경우가 더 많았어요" 같은 문장은 집단의 폐업률을 비교하지 않았으므로 쓰지 않는다. 사실 정보(업력, 블로그 언급 수)는 그대로 쓸 수 있다.
- **MDIS 조사명:** "소상공인실태조사 2023"이다. "창업기업실태조사"는 쓰지 않는다.
- 금지어 검사 목록(2절)에 위 규칙의 문자열(`후기`, `리뷰`, `받을 수 있는`, `관련`, `창업기업실태조사`)을 W3-16에서 함께 검사한다. `관련`은 정책 카드 문맥에서만 오류로 본다.
