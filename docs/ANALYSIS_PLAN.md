# Analysis Plan

> 이 문서는 현재 분석 방향의 기준 문서다. 데이터 확인 후 방법이 변경되면 `DECISIONS.md`에 이유를 기록하고 이 문서를 갱신한다.

## 1. Detect — 폐업 위험 탐지

개업 이후 폐업까지의 기간과 아직 영업 중인 사업체를 함께 다루기 위해 survival analysis를 적용한다. 각 분기 말을 기준으로 이후 12개월 내 폐업 여부를 예측하고 업종·지역·업력에 따른 위험 구조를 파악한다.

이어 사업체와 주변 상권 특성을 투입한 gradient boosting 모형으로 개별 사업체의 폐업 위험을 추정한다.

### Validation
- AUC, C-index 등을 활용해 성능을 평가한다.
- random split과 temporal split을 모두 수행하고 결과를 비교한다.
- random split에서 미래 시점 정보 유입으로 성능이 과대평가될 가능성을 점검한다.
- 추정 확률은 실제 폐업 빈도와의 일치도를 확인하고 필요 시 calibration한다.
- 불확실성을 함께 제시하는 방식을 검토한다.

## 2. Diagnose — 위험요인 진단

예측모형의 변수 기여도를 SHAP으로 분해하여 개별 사업체의 위험도가 어떠한 관측 특성에서 비롯되었는지 파악한다.

위험요인은 다음 유형을 기본으로 재구성한다.
- 입지·수요
- 경쟁
- 비용
- 사업체 구조

동일 업종 및 유사 상권 사업체와 비교한 상대적 수준으로 환산해 사용자가 이해할 수 있는 형태로 제시한다.

각 요인은 다음과 같이 구분한다.
- 사업자가 직접 개선할 수 있는 요인
- 정책적 지원이 필요한 요인
- 단기간에 변경하기 어려운 외부 요인

개선방향은 앞의 두 유형을 중심으로 검토하고 외부 요인은 위험 배경 설명에 활용한다.

## 3. Prescribe — 개선방향 제시

진단된 위험요인 중 사업자가 직접 개선할 수 있거나 정책적 지원을 통해 변화시킬 수 있는 요인 가운데 **데이터로 검증 가능한 핵심 요인 1개를 우선 선정**한다.

선정한 요인에 대해서는 업종·지역·사업체 규모 등 주요 특성을 고려하여 유사한 사업체 간 경영성과 차이를 비교한다. 데이터에 충분한 시점 정보가 존재하는 경우에는 변화 전후의 차이도 분석한다.

목표는 SHAP의 예측 기여도를 곧바로 처방으로 변환하는 것이 아니라, 개선방향에 별도의 통계적 근거를 부여할 수 있는지를 확인하는 것이다.

분석 조건이 충분하지 않거나 결과가 명확하지 않으면 효과를 단정하지 않는다. 최종 표현 방식은 실제 분석 방법과 식별 수준에 맞추어 결정한다.

추가로 사업체의 업종·지역·업력 등과 정부·지자체 소상공인 지원사업의 자격조건을 매칭하여 진단된 위험요인과 관련된 지원정책을 제시한다.

## 4. Prototype

사용자가 자신의 점포를 검색하면 다음 정보를 단계적으로 제공하는 웹 프로토타입을 목표로 한다.
1. 폐업 위험 수준 및 불확실성
2. 주요 위험요인
3. 대응 가능 여부
4. 근거 수준이 표시된 개선방향
5. 이용 가능한 지원정책
