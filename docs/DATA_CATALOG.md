# Data Catalog

데이터를 코드에 사용하기 전에 이 문서에 출처, 시간 범위, 단위, 주요 변수, 사용 목적, 검증 상태를 기록한다.

상태는 `VERIFIED`, `PARTIAL`, `UNVERIFIED` 중 하나를 사용한다.

| 데이터 | 예상 용도 | 시간 단위 | 상태 | 확인할 사항 |
|---|---|---|---|---|
| 지방행정 인허가 데이터 | 개·폐업 시점 및 영업 상태 | 사업체/시점 | UNVERIFIED | 폐업·이전·업종전환 구분 기준 |
| 소상공인시장진흥공단 상가(상권)정보 | 사업체·업종·위치 정보 | 사업체/분기 | UNVERIFIED | 인허가 데이터와 매칭키·매칭률 |
| 서울시 상권분석 데이터 | 수요·경쟁·상권 특성 | 분기 | UNVERIFIED | 제공 기간, 공간 단위, 변수 정의 |
| 생활인구·지역 인구 자료 | 유동·배후수요 | 시점/공간 | UNVERIFIED | 분기 집계 방법, 공간 매칭 |
| 임대 관련 지표 | 비용 환경 | 시점/공간 | UNVERIFIED | 세부 공간 단위 및 제공 주기 |
| 네이버 온라인 정보 | 온라인 존재감 후보 | 현재/수집시점 | UNVERIFIED | 공식 수집 범위, 점포 매칭률, 과거시점 사용 금지 |
| 카카오 온라인 정보 | 온라인 존재감 후보 | 현재/수집시점 | UNVERIFIED | API 응답 필드, 점포 매칭률, 과거시점 사용 금지 |
| MDIS 사업체 자료 | Stage 3 후보 효과 분석 | 자료별 | UNVERIFIED | 사용 가능 변수, 표본, 결과변수, 분석 가능 범위 |

## 등록 규칙
새 데이터셋을 추가할 때 최소한 다음을 확인한다: 원 출처, 다운로드/접근일, 관측 단위, 시간 범위, 공간 단위, 주요 변수 정의, 결측률, 다른 데이터와의 매칭 방식, 라이선스·이용 조건.
