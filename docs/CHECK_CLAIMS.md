# 공개 문구·식별정보 검사 (W3-16)

`python scripts/check_claims.py docs app/out <제출본문.md> <공개번들폴더> --fail-on warn`

경로는 실제 존재하는 경로로 지정한다. 정적 번들은 manifest만 지정하지 말고 reports,
search_index 등을 포함하는 폴더 전체를 지정한다. manifest의 외부 경로를 자동 추적하지 않는다.
Markdown, HTML/HTM/SVG, JSON/JSONL, 텍스트·CSV·소스 파일을 검사한다.
HTML 엔터티와 태그로 나뉜 문구, JSON Unicode escape도 검사한다.
줄은 원본 기준이며 정규화한 문구의 열은 원본 바이트 위치와 다를 수 있다.
HTML은 원문과 태그 제거본을 검사하므로 같은 내용이 두 번 보고될 수 있다.
PDF·이미지·영상은 직접 읽지 않는다. 추출/OCR한 텍스트를 별도 지정하고 화면도 검수한다.

## 범위와 결과

- 재귀 탐색에서 루트 `data/`, `outputs/`, 의존성·캐시 폴더와 링크는 제외한다.
  공개 산출물인 `outputs/submission` 등을 명시하면 해당 경로는 검사한다.
  루트 `data/` 직접 지정은 거부한다. 내부 모델 산출물을 일괄 공개 검사하지 않는다.
- 종료 코드: 0=설정한 실패 기준 미만, 1=검출, 2=입력/설정 오류, 3=검사 파일 없음.
  `--fail-on warn`을 제출 전 기준으로 사용한다. warn은 문맥 검수가 필요한 항목이다.
  binary/extension/decode/링크 등 skipped 항목도 반드시 확인한다.
- 규칙은 `configs/claims_rules.json`, 예외는 `configs/claims_allowlist.json`에 있다.
  `--rules`, `--allowlist`로 별도 설정을 지정할 수 있다.
  줄 예외 `claims-allow: CL-17`은 검수한 문맥에만 사용하고 변경 내용을 리뷰한다.
  예외는 데이터의 안전성을 증명하지 않는다.
- 결정 기록과 CLAIMS는 CL 규칙만 예외이며 식별정보 검사는 계속한다.
  규칙/검사기/합성 테스트 파일 자체는 기존 경로 예외를 유지한다.

## 주요 규칙과 한계

- T3: 개인 확률 문구, 명시된 금지 수치, 퍼센트 구간, 숫자 값을 갖는
  `probability_12m`/`ci_low`/`ci_high` 공개 JSON 필드를 검사한다.
  일반 통계 범위나 같은 이름의 집계 CI도 걸릴 수 있으므로 검토한 줄만 예외 처리한다.
  내부 확률 구간을 생성하는 `regen_w3.json` 설정은 변경하지 않는다.
  공개 스키마 제외 여부는 그 파일의 W3-14 open item으로 남아 있다.
- S12: 철회 수치와 오탐-폐업 상관, 철회 카드 문구를 검사한다.
- A3: SR 계열 ID와 store_id 값, 상호/사업장명 필드, store_id와 함께 있는 JSON name,
  상세 도로명·지번 패턴과 주소 필드, 사업자번호, 전화번호, row_key/관리번호/PNU를 검사한다.
  식별정보 매치·문맥·출력 경로는 마스킹한다.
- T1/S5/T4 및 CLAIMS: 효과/인과/개인 효과 단정, 지원 효과 단정, 모델·조사명 오류,
  온라인 지표·지원사업 제목·위험요인 표현을 검사한다.
  신청 가능·관련 등은 정상 문맥도 있으므로 warn으로 검수한다.
- `SAMPLE-숫자`, `SYN-숫자` 값 자체는 허용한다. 문서 전체를 합성으로 예외 처리하지 않는다.
  명시적인 `(샘플)` 이름·주소와 비식별 사례 표기는 허용하지만,
  실제 주소 형태·전화번호·금지 주장까지 허용하지 않는다.
  W3-14로 갱신한 W2 합성 static 번들은 개인 확률/구간을 포함하지 않는다. 상세 주소 형태는 별도 A3 검사에서 계속 검출된다.
- 임의의 상호를 문맥 없이 모두 식별할 수는 없다. 라벨 없는 실명 상호, 변형 주소,
  CSV의 임의 열, 압축/동적 JS 및 여러 HTML 노드 사이 공백 등은 누락될 수 있다.
  공개 대상의 실제 상호·주소 목록을 승인된 비공개 규칙 파일의 ID 패턴으로 추가해
  `--rules`로 검사하고 수동 검색을 병행한다. 그 목록이나 원자료를 커밋하지 않는다.
  정규식 사전을 만들 때 문자열을 escape해야 한다. 본 도구의 통과는 익명화 인증이 아니다.
