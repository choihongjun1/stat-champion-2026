- 사례 A: 최종 2026Q2 serving 대상 중 high, 업종 또는 구 조건으로 matched되는 공개 가능 맞춤 정책 2건 이상, 공개 부적합 점포 제외. 맞춤 matched 정책 수 내림차순 → interpretation_sensitive=false → 표시 가능한 진단 요인 수 내림차순으로 정렬한 상위 10곳 중 seed 20261004로 1곳. 후보가 없으면 high + 맞춤 matched 1건 이상(대안1), 다음 mid + 맞춤 matched 2건 이상(대안2), 그래도 없으면 “적합한 비식별 실제 사례 없음”.
- 사례 B: 최종 2026Q2 serving 대상 중 high, 업종·구 조건 matched 정책 0건이며 공통 사업만 표시, 공개 부적합 제외. interpretation_sensitive=false → 표시 가능한 진단 요인 수 내림차순으로 정렬한 상위 10곳 중 seed 20261005로 1곳. 없으면 “적합한 비식별 실제 사례 없음”.
- 사례 C: 최종 2026Q2 serving 대상 중 low, 공개 부적합 제외. 가능하면 A와 같은 업종, 없으면 업종 무관. interpretation_sensitive=false 순으로 정렬한 상위 10곳 중 seed 20261006으로 1곳. 없으면 “적합한 비식별 실제 사례 없음”.
- 공통: 서로 다른 점포, 개인 확률로 정렬하지 않음. 표기 “비식별 실제 사례 A/B/C”, 공개물에는 구·업종만 사용. 안정성 우선은 위험이 더 낮거나 더 좋은 점포라는 뜻이 아님. 적용 단계(기본/대안1/대안2/없음), 후보 수·seed를 기록. 결과를 본 뒤 규칙 변경 금지. 정책 파일 경로·전체 해시·확인일을 로컬 설정에 고정하며 파일 변경 시 자동 재선택하지 않고 중단. 보고용 해시는 앞 16자만 사용.
