### T5 보완 확정 준비 (최홍준, 2026-10-03)

> 게시 전 초안. #49 손유성 수정 제안 5955352405를 반영했습니다. 실제 정책 파일 수신과 검증, 팀 확인 전에는 최종 확정하지 않습니다.

- 맞춤 정책 수(tailored_policy_count): 공개 가능·모집 중으로 검수된 표시 정책 중 업종 또는 구 조건이 점포와 맞는 정책 수. 원천 conditions와 기존 matched_by 증거를 대조합니다. matched와 check_required 모두 포함하고 공통 사업은 세지 않습니다. matched는 데이터로 자격 조건까지 확인됨, check_required는 업종·지역 조건이 맞지만 나머지 조건은 공고에서 확인 필요함을 뜻합니다. 화면에는 “조건 확인 필요”로 설명하며 위험요인과 정책을 인과적으로 연결하지 않습니다.
- 사례 A: 최종 2026Q2 serving 대상 중 high, 맞춤 정책 2건 이상, 공개 부적합 점포 제외. 맞춤 정책 수 내림차순 → interpretation_sensitive=false → 표시 가능한 진단 요인 수 내림차순 → 결정적 동률 정렬 후 상위 10곳 중 seed 20261004로 1곳. 후보가 없으면 high + 맞춤 1건 이상(대안1), 다음 mid + 맞춤 2건 이상(대안2), 그래도 없으면 “적합한 비식별 실제 사례 없음”. check_required만 있는 점포도 허용하며 matched 수는 동률 판정에 사용하지 않습니다.
- 사례 B: A를 제외한 공개 가능한 high 후보 중 맞춤 정책 수 최소값을 계산하고 그 값의 후보만 사용합니다. 실제 0건 후보가 있으면 0건, 없으면 실제 최소값을 사용하며 1건을 고정하지 않습니다. interpretation_sensitive=false → 표시 가능한 진단 요인 수 내림차순 → 결정적 동률 정렬 후 상위 10곳 중 seed 20261005로 1곳. high 후보가 없으면 “적합한 비식별 실제 사례 없음”. 실제 최소값은 공개 요약 B 행의 tailored_policy_count_min에 기록하며 후보가 없으면 null입니다. 최종 파일 수신 전 실제 최소값과 B 최종 확인은 미확정입니다.
- 사례 C: 최종 2026Q2 serving 대상 중 low, 공개 부적합 제외. 가능하면 A와 같은 업종, 없으면 업종 무관. interpretation_sensitive=false 순으로 정렬한 상위 10곳 중 seed 20261006으로 1곳. 없으면 “적합한 비식별 실제 사례 없음”.
- 공통: 서로 다른 점포, 개인 확률로 정렬하지 않음. 표기 “비식별 실제 사례 A/B/C”, 공개물에는 구·업종만 사용. 안정성 우선은 위험이 더 낮거나 더 좋은 점포라는 뜻이 아님. 적용 단계(기본/대안1/대안2/없음), 후보 수·seed를 기록. 결과를 본 뒤 규칙 변경 금지. 정책 파일 경로·전체 해시·확인일을 로컬 설정에 고정하며 파일 변경 시 자동 재선택하지 않고 중단. 보고용 해시는 앞 16자만 사용.
